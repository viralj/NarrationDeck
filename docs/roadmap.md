# Roadmap / Backlog

This file tracks remaining items and enhancements. Items are grouped by
Resolve Free vs Studio (where applicable).

## Remaining from Original Plan (Resolve Free compatible)
- Subtitles fallback: if Text+ preset is missing, create a native subtitle track from SRT.
- Input validation for manual media import (exactly 1 audio + 1 SRT + N images).
- Caption chunking controls (max chars per line, max duration, lines per caption).
- Mapping preview dialog (show matches/mismatches before export).

## Blocked in Resolve Free (Studio or manual steps)
- Automated crossfades between images.
- Automated Text+ fade in/out.
- External GUI -> Resolve connection (no in-Resolve scripting needed in Studio).

## Recommended Enhancements
- Batch processing (multiple folders).
- Preset profiles (save/load GUI configuration).
- Output naming templates (prefix + date/time patterns).
- Better matching tools (duplicate-snippet disambiguation).
- Shotcut/Kdenlive export tweaks (MLT metadata, transitions).
